## 🎨 测试设计模式

### 测试基础设施
- **TestBase**: 提供通用测试数据和工具方法
- **TestDataFactory**: 专门的测试数据创建工厂
- **TestConfig**: 测试环境配置和 Mock 设置

### 测试组织结构
- **@Nested**: 逻辑分组相关测试
- **@DisplayName**: 清晰的中文测试描述
- **AAA 模式**: Arrange-Act-Assert 结构

### Mock 和存根
- **Mockito**: 应用服务层 Mock 依赖
- **@DataJpaTest**: 数据库层测试切片
- **@WebMvcTest**: Web 层测试切片

## 🚀 运行方式

### 快速运行
```bash
# 给脚本执行权限
chmod +x run-tests.sh

# 运行所有测试
./run-tests.sh

# 分类运行
./run-tests.sh unit        # 单元测试
./run-tests.sh integration # 集成测试
./run-tests.sh e2e         # 端到端测试
./run-tests.sh coverage    # 覆盖率报告
```

### Gradle 命令
```bash
# 运行所有测试
./gradlew test

# 运行特定测试
./gradlew test --tests StationTest
./gradlew test --tests "**/domain/model/**/*Test"

# 生成覆盖率报告
./gradlew clean test jacocoTestReport
```
